# پیام‌رسان آزاد — نسخه اولیه

این پروژه یک نمونه اولیه قابل اجرا از پیام‌رسان است:
- ثبت‌نام فقط با نام کاربری و رمز عبور (بدون شماره و ایمیل)
- گفت‌وگوی خصوصی متنی
- ارسال فایل، تصویر، ویدئو و پیام صوتی
- به‌روزرسانی پیام‌ها در لحظه وقتی کاربر آنلاین باشد
- رابط سیاه‌وسفید وب‌اپ نصب‌پذیر (PWA) برای افزودن به صفحه اصلی اندروید

## اجرای آزمایشی روی کامپیوتر
1. Node.js نسخه 18 یا بالاتر نصب کنید.
2. در پوشه پروژه دستور `npm install` را اجرا کنید.
3. برای اجرا: `npm start`
4. در مرورگر آدرس `http://localhost:3000` را باز کنید.

## نصب روی اندروید
پس از انتشار پروژه روی یک هاست دارای HTTPS، با Chrome اندروید نشانی سایت را باز کنید و از منوی مرورگر گزینه «Install app» یا «Add to Home screen» را بزنید. در این نسخه فایل APK مستقل ساخته نشده است؛ برنامه به شکل وب‌اپ نصب‌پذیر اجرا می‌شود.

## استفاده از راه دور
برای ارتباط بین شهرها/کشورها، سرور باید روی اینترنت عمومی و با HTTPS اجرا شود. اتصال صرفاً به Wi-Fi بدون اینترنت فقط برای شبکه محلی قابل استفاده است. این پروژه خودش میزبان عمومی ندارد و برای استفاده واقعی باید روی سرور deploy شود.

## پیش از انتشار عمومی ضروری است
- مقدار `JWT_SECRET` را به یک مقدار تصادفی و محرمانه تغییر دهید.
- HTTPS اجباری کنید.
- محدودیت نرخ برای ورود/ثبت‌نام و کنترل سوءاستفاده اضافه کنید.
- سیاست نگهداری و حذف فایل‌ها و پیام‌ها، پشتیبان‌گیری و گزارش تخلف تعریف کنید.
- اسکن بدافزار و محدودیت نوع/حجم فایل‌ها را برای محیط عمومی اضافه کنید.
- این نسخه رمزنگاری سرتاسری (E2EE)، تماس صوتی/تصویری، کانال، استوری، همگام‌سازی چنددستگاهی یا امکانات کامل روبیکا را ندارد.

## نکات
نام کاربری فقط شامل حروف انگلیسی، عدد و زیرخط است و ۳ تا ۲۰ کاراکتر دارد. رمز حداقل ۶ کاراکتر است. فایل‌ها تا ۱۰۰ مگابایت پذیرفته می‌شوند. این مقادیر برای نمونه اولیه هستند، نه تنظیمات امنیتی نهایی.
